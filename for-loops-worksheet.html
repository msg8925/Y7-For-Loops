Reminder — the FOR loop: FOR N ← 1 TO 5 … NEXT N. The loop variable starts at the start value, the loop body runs, and NEXT adds the STEP (1 unless you say otherwise). The loop stops once the loop variable goes past the end value. The end value is included. In a trace table, each row is one trip round the loop.

Challenge — combine what you know

[ 6 marks ]

Scenario: A program works out the total age of a group of students waiting at a bus stop. The program asks the user how many students there are. It then uses a FOR loop to ask for each student's age one at a time. After the loop it outputs the total of all the ages.

Requirements:

• INPUT the number of students, then loop that many times.
• Inside the loop, INPUT one age and add it to a running Total.
• Set the Total to 0 before the loop starts.
• OUTPUT the Total after the loop has finished.

Hint: your loop will look like FOR Student ← 1 TO NumberOfStudents. Think about how it is similar to the “Totalling” program from the explainer.
