FOR Loops

How to make a computer repeat instructions — and how to trace exactly what happens each time round.

01

Why do we need loops?

Imagine you want to output the numbers 1 to 5. Without a loop you would write one OUTPUT for each number:

OUTPUT 1
OUTPUT 2
OUTPUT 3
OUTPUT 4
OUTPUT 5

That is fine for 5 numbers. But what about 1000? Nobody wants to type 1000 lines. A loop lets us write the instruction once and tell the computer how many times to repeat it.

Real-world analogyThink of a PE teacher saying "Do 10 star jumps." She does not say "do a star jump" ten separate times. She says it once and gives a number. A FOR loop works the same way: repeat this, this many times.
02

The FOR loop in Cambridge Pseudocode

A FOR loop is a count-controlled loop: we know in advance how many times it will repeat. Here is the same program from before, written with a loop:

FOR Count ← 1 TO 5
    OUTPUT Count
NEXT Count
Syntax card
FOR <identifier> ← <start> TO <end>
    <statements to repeat>
NEXT <identifier>
Count — the loop variable (also called the counter). It changes every time round.
← 1 — the start value. Count begins as 1.
TO 5 — the end value. The loop stops after Count has been 5.
NEXT Count — marks the end of the loop body, and adds 1 to Count.
IndentationThe lines between FOR and NEXT are the loop body. We indent them so we can see at a glance what gets repeated.
RememberThe end value is included. FOR Count ← 1 TO 5 runs for 1, 2, 3, 4 and 5 — that is 5 repeats, not 4.
03

What is a trace table?

A trace table is how we act like the computer. We go through a program one step at a time and write down what every variable holds. It is the best way to understand a loop, and to find mistakes in one.

For a FOR loop, each row of the trace table is one trip round the loop (one iteration). Each column is a variable, plus a column for any OUTPUT.

How the computer runs a FOR loop 1. Set the loop variable to the start value.
2. Check: is the loop variable still less than or equal to the end value? If NO, jump past NEXT — the loop is finished.
3. If YES, run every line in the loop body.
4. At NEXT, add 1 to the loop variable and go back to step 2.

05

Counting in different steps

By default a FOR loop counts up by 1. Add STEP to count in bigger jumps, or to count down.

FOR N ← 2 TO 10 STEP 2
    OUTPUT N
NEXT N
// outputs 2, 4, 6, 8, 10

FOR N ← 10 TO 0 STEP -5
    OUTPUT N
NEXT N
// outputs 10, 5, 0
Counting downTo count down, the start must be bigger than the end, and the STEP must be negative. If you forget the negative STEP, the loop will not run at all, because the very first check (is 10 ≤ 0?) already fails.

07

Key points

• A FOR loop repeats a block of code a set number of times.
• The loop variable changes each time round and the end value is included.
• STEP changes the size of the jump, and a negative STEP counts down.
• A trace table has one row per iteration and one column per variable.
• Work on the worksheet next: you will complete more trace tables, then write your own FOR loop in the pseudocode editor.

Tip: when a loop gives the wrong answer, trace it — the mistake always shows up in the table.
